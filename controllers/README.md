# Controladores

- `single_drone/buttons/`: panel de botones para un dron.
- `single_drone/camera/`: control por cámara y gestos para un dron.
- `single_drone/flowdeck/`: hover y control por teclado con Flow Deck.
- `two_drones/`: todo lo específico de dos drones, incluidos botones, cámara, Flow Deck, multiprocesamiento, backends, logs y análisis.
- `joystick/`: control mediante marker/mocap usado como joystick.
- `shared/`: utilidades comunes, sin lógica de vuelo propia.

Consulta `../docs/agents/architecture.md` para las dependencias entre categorías.
